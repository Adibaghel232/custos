# CLAIMS: where every number in the final deck comes from

Generated by `scripts/build_deck.py` (the mapping below is produced from the code that places each number, so it cannot drift).
Every number on a slide is read from the bench outputs of one run (`metrics.json` is the source of truth; `cells.csv`, `compute.csv`, `run.json`/`run_meta.json` where noted). If a key is absent the deck prints `not measured`. The values of the run that built the deck are in `deliverables/claims_values.csv`.

Literature numbers (MINJA 76.8%, AgentPoison <0.1% / >80%, PromptArmor 42.5% / 67.67% TPR, A-MemGuard >95% retrieval / ~60% indirect) are citations, not measurements: see the reference list (slide A7).

Key syntax: `by_defence.<D>.<Metric>` with D0 undefended, D1 PI filter, D2 A-MemGuard-style, D3 Custos, D3-<x> ablations; a rate dict carries `rate, ci_low, ci_high, n, k, r3_upper` (Wilson 95%).
